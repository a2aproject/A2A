a2a.plugins.types module
************************

Argument types passed to plugin hooks.

Hooks return "None". Per-call state lives in "context.state" (server
and client) or "PushRequest.state" (push), which the SDK passes
unchanged from a before-hook to the matching after-hook.

class a2a.plugins.types.ServerResponse(method: str, payload: Any, context: ServerCallContext, error: BaseException | None = None, is_stream_event: bool = False, is_final: bool = True)

   Bases: "object"

   A handler result, passed to *ServerPlugin.after_handler_run*.

   For a unary call the hook runs once with "is_final=True". For a
   stream it runs once per event with "is_stream_event=True,
   is_final=False" and once more with "is_final=True" and
   "payload=None" when the stream ends, including on error or client
   disconnect.

   method

      Method name.

      Type:
         str

   payload

      The handler result or stream event, "None" on error or stream
      end.

      Type:
         Any

   context

      The same call context passed to *before_handler_run*.

      Type:
         ServerCallContext

   error

      The exception raised by the handler, if any.

      Type:
         BaseException | None

   is_stream_event

      Whether "payload" is one event of a stream.

      Type:
         bool

   is_final

      Whether this is the last call for the request.

      Type:
         bool

   context: ServerCallContext

   error: BaseException | None = None

   is_final: bool = True

   is_stream_event: bool = False

   method: str

   payload: Any

class a2a.plugins.types.TaskEventInfo(task_id: str, from_state: TaskState | None, to_state: TaskState, event: Event | None, task: Task, context: ServerCallContext)

   Bases: "object"

   A successful task write, passed to
   *TaskObserverPlugin.on_task_event*.

   task_id

      ID of the task.

      Type:
         str

   from_state

      Persisted state before the write, "None" when the write created
      the task.

      Type:
         TaskState | None

   to_state

      State after the write. Equal to "from_state" for writes that do
      not change the state, such as artifact updates.

      Type:
         TaskState

   event

      The event that caused the write, "None" when the SDK wrote the
      task without one.

      Type:
         Event | None

   task

      The task after the write. This is the SDK's live object; copy it
      if you keep it beyond the hook call.

      Type:
         Task

   context

      Call context of the request that produced the write.

      Type:
         ServerCallContext

   context: ServerCallContext

   event: Event | None

   from_state: TaskState | None

   task: Task

   task_id: str

   to_state: TaskState
