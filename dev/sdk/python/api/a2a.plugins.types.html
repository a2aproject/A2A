a2a.plugins.types module¶

Argument types passed to plugin hooks.

Hooks return None. Per-call state lives in context.state (server and client) or PushRequest.state (push), which the SDK passes unchanged from a before-hook to the matching after-hook.

class a2a.plugins.types.ServerResponse(method: str, payload: Any, context: ServerCallContext, error: BaseException | None = None, is_stream_event: bool = False, is_final: bool = True)¶

Bases: object

A handler result, passed to ServerPlugin.after_handler_run.

For a unary call the hook runs once with is_final=True. For a stream it runs once per event with is_stream_event=True, is_final=False and once more with is_final=True and payload=None when the stream ends, including on error or client disconnect.
