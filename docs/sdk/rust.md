# Rust SDK

The Rust SDK, `a2a-rs`, provides the A2A types, a client, a server, a gRPC transport and a command-line tool, `a2acli`.

- [Documentation](https://a2aproject.github.io/a2a-rs/)
- [API reference on docs.rs](https://docs.rs/a2a-lf)
- [Source code on GitHub](https://github.com/a2aproject/a2a-rs)
