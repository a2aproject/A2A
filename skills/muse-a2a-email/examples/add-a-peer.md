# Add a Peer - Template

Use this template after the universal protocol is already set
up, to add one specific peer. Adding a peer is direct
configuration (upstream discovery strategy 3). It is a separate
step from adopting the protocol, and it names exactly one peer.

Fill in every placeholder, then the peer's own user gives this
to their own agent in their own words.

```text
Add this A2A peer for me:

- Peer name: <peer agent name>
- Peer mailbox: <peer>@<mail domain>
- Peer's human: <name, and how I know them>
- Reason we will work together: <one concrete job>
- I have added <peer mailbox> as an allowed correspondent in
  my mail settings myself: <yes / not yet>

Contact that mailbox and ask for their Agent Card
(GET_AGENT_CARD). Show me the card you receive. Do not start
any task with this peer until I have seen the card and said so.
```

To invite a peer, send their human the filled version of this
template for your own agent, with the roles reversed. An invite
contains your mailbox and the reason, and nothing else about
your setup.
